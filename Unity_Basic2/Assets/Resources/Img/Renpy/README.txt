--------------- 폴더 설명 --------------------



--- psd파일 ---

포토샵 파일 확장자 모음집입니다
수정작업이 이루어진 psd 파일이 모두 있습니다

-파일 설명

ui 폴더 - 수정한 ui의 psd 파일입니다

BACKGROUND - 초기 배경 작업 파일입니다

character - 중완님께서 요청하셔서 캐릭터작업한걸 약간 정리해서 모아놓은 파일입니다

mob - 모브캐릭터는 메인 보다 사이즈를 줄여 새롭게 옮겨 작업한 파일입니다

배경완성본 - 정한 배경 사이즈 비율에 맞춰 작업한 파일입니다

캐릭터 작업 - 캐릭터들을 메인으로 작업 한 파일입니다 #모브는 mob 파일로 이동

화면 구성 - gui 이미지 작업에 들어가면서 화면 구성을 보기 위해 구성해본 파일입니다



--- 공유받은 베이스 리소스 ---

배경소스2가 최종 배경 소스 입니다
다른분들께 제공 받은 리소스 입니다



--- 공유한 리소스 ---

구글 드라이브에 공유한 파일들입니다

-파일 설명

gui - ui 수정 파일입니다 파일 구성을 복붙 해서 넣을 수 있도록 했습니다
image - ui를 제외한 이미지 리소스 전체 공유 본입니다 images 파일 안에 그대로 넣을 수 있도록 작업 했습니다
메인 캐릭터 - 3명의 주요 캐릭터의 생성 이미지 입니다
서브 캐릭터 - 모브를 위한 생성 이미지 풀입니다
main - 메뉴 이미지입니다
menu - 메뉴 ui입니다 리소스 변경되었습니다



--- 문서 파일 ---

작업을 위한 문서 파일입니다

-파일 설명

릴리아 표정 - 릴리아에 대한 표정 가이드 입니다 강민님이 작업 해주셨습니다 그외 추가 사항들도 기록 해뒀습니다
이미지 정의 - 스크립트상 이미지를 지정해 정의한 구문모음입니다 제가 작성 후 상준님께서 오탈자 검수 해주셨습니다
캐릭터_표정정리표 - 개발 초기 리소스 작업을 위해 요청해 강민님께서 제공해주신 파일입니다
